# DeepSeek Telegram Investment Bot

Telegram-бот-ассистент по инвестициям и личным финансам поверх
[DeepSeek API](https://platform.deepseek.com/). Пользователь пишет вопрос в
личном чате — бот пересылает его в DeepSeek (модель `deepseek-chat` или
`deepseek-reasoner`) и возвращает ответ.

Бот **не хранит историю диалогов**: каждое сообщение обрабатывается как
независимый запрос. Это упрощает архитектуру, снижает расход токенов,
исключает утечку контекста между разными пользователями и не даёт финансовым
вопросам пользователя накапливаться без явной необходимости.

⚠️ Бот не является лицензированным финансовым советником, а его ответы не
являются индивидуальной инвестиционной рекомендацией и не гарантируют
доходность — это явно проговаривается пользователю в `/start` и `/help`.

## Возможности

- Приём текстовых сообщений в личных чатах Telegram.
- Пересылка запроса в DeepSeek API (OpenAI-совместимый интерфейс) с системным
  промптом, задающим доменную роль и обязательные дисклеймеры.
- Индикация статуса «печатает…» на время ожидания ответа.
- Команды `/start` и `/help`.
- `/research_response_format` — технический режим для исследования влияния параметров DeepSeek
  API на форму ответа (JSON-режим `response_format`, `max_tokens`, `stop` — для
  последних двух значение вводит сам пользователь); не предназначен для
  обычных вопросов. После каждого сценария бот показывает минимальную
  статистику ответа (`finish_reason`, использованные токены); сообщения,
  ожидающие выбора или ввода от пользователя, помечены значком 👉 — в отличие
  от результатов сценария (значок 📊) и статистики (значок 📈).
- Обработка ошибок сети, аутентификации и превышения лимитов API с понятными
  сообщениями пользователю на русском языке.
- Никаких админ-команд и возможности сменить модель/системный промпт из чата —
  это осознанное ограничение поверхности атаки.
- Бот не запрашивает и не хранит чувствительные персональные/финансовые
  данные (номера счетов и карт, паспортные данные, ИНН и т.п.).

## Технологии

- Python 3.10+
- [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) v20+
- [openai](https://github.com/openai/openai-python) SDK (используется как клиент для DeepSeek — API совместимо с OpenAI)
- [python-dotenv](https://github.com/theskumar/python-dotenv) для загрузки конфигурации

## Установка и настройка

### 1. Клонируйте репозиторий и создайте виртуальное окружение

```bash
git clone <URL-этого-репозитория>
cd investment-telegram-bot
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

### 2. Установите зависимости

```bash
make install
# или напрямую:
pip install -r requirements.txt
```

### 3. Получите токен Telegram-бота у BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям (укажите имя и username бота).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
4. Сохраните этот токен — он понадобится на следующем шаге.

### 4. Получите API-ключ DeepSeek

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com/).
2. Пополните баланс (при необходимости) в разделе биллинга.
3. Перейдите в раздел [API Keys](https://platform.deepseek.com/api_keys) и создайте новый ключ.
4. Скопируйте ключ — он показывается только один раз.

### 5. Настройте переменные окружения

```bash
cp .env.example .env
```

Откройте `.env` и заполните значения:

```dotenv
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
DEEPSEEK_API_KEY=ваш_ключ_deepseek
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

**Важно:** файл `.env` уже добавлен в `.gitignore` — никогда не коммитьте его
и не публикуйте содержащиеся в нём ключи.

Структура JSON-ответа сценария 2 в `.env` не выносится — она задана константами в
`src/research_response_format.py`, так как является предметом самого исследования, а не настройкой
поведения бота. Параметры сценариев 3 (`max_tokens`) и 4 (стоп-слова) в `.env` тоже не
задаются — их вводит сам пользователь в диалоге `/research_response_format`.

### 6. (Опционально) Настройте pre-commit хуки

Хуки проверяют код перед коммитом, включая поиск случайно закоммиченных секретов:

```bash
pip install pre-commit detect-secrets
detect-secrets scan > .secrets.baseline
pre-commit install
```

## Запуск

```bash
make run
# или напрямую:
python src/main.py
```

При успешном запуске в логах появится сообщение:

```
INFO - __main__ - Бот запущен. Модель DeepSeek: deepseek-chat
```

Откройте бота в Telegram и отправьте `/start`.

## Команды бота

| Команда      | Описание                                                                 |
|--------------|---------------------------------------------------------------------------|
| `/start`     | Приветственное сообщение и краткая инструкция                             |
| `/help`      | Справка по использованию и ограничениям бота                              |
| `/research_response_format`  | Технический режим сравнения сценариев ограничений DeepSeek API            |
| `/cancel`    | Досрочный выход из режима `/research_response_format`                                     |

## Ограничения и особенности

- Бот отвечает только на текстовые сообщения в **личных чатах** (групповые чаты игнорируются).
- Максимальная длина запроса пользователя ограничена переменной `MAX_INPUT_CHARS` (по умолчанию 4000 символов).
- История диалога не сохраняется — контекст предыдущих сообщений не учитывается
  (в `/research_response_format` вопрос временно хранится только на время самого диалога и не переживает выход из режима).
- Пользователь не может сменить модель, системный промпт или иные параметры генерации.
- Бот не запрашивает и не должен получать чувствительные персональные/финансовые данные
  (номера счетов и карт, паспортные данные, ИНН, точные суммы на счетах).

## Безопасность

- Все секреты (токен бота, API-ключ) загружаются только из переменных окружения / `.env`.
- `.env` находится в `.gitignore` и не должен попадать в git.
- В коде нет захардкоженных ключей или админ-бэкдоров.
- Рекомендуется использовать `pre-commit` с `detect-secrets` для дополнительной защиты от случайных утечек.
