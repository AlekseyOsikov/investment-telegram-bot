# DeepSeek Telegram Proxy Bot

Простой и безопасный Telegram-бот, работающий прокси между пользователями и
[DeepSeek API](https://platform.deepseek.com/). Пользователь пишет боту в
личном чате — бот пересылает текст в DeepSeek (модель `deepseek-chat` или
`deepseek-reasoner`) и возвращает ответ.

Бот **не хранит историю диалогов**: каждое сообщение обрабатывается как
независимый запрос. Это упрощает архитектуру, снижает расход токенов и
исключает утечку контекста между разными пользователями.

## Возможности

- Приём текстовых сообщений в личных чатах Telegram.
- Пересылка запроса в DeepSeek API (OpenAI-совместимый интерфейс).
- Индикация статуса «печатает…» на время ожидания ответа.
- Команды `/start` и `/help`.
- Обработка ошибок сети, аутентификации и превышения лимитов API с понятными
  сообщениями пользователю.
- Никаких админ-команд и возможности сменить модель/системный промпт из чата —
  это осознанное ограничение поверхности атаки.

## Технологии

## Установка и настройка

### 1. Клонируйте репозиторий и создайте виртуальное окружение

```bash
git clone <URL-этого-репозитория>
cd investment-telegram-bot
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

### 2. Установите зависимости

```bash
make install
# или напрямую:
pip install -r requirements.txt
```

### 3. Получите токен Telegram-бота у BotFather

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям (укажите имя и username бота).
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
4. Сохраните этот токен — он понадобится на следующем шаге.

### 4. Получите API-ключ DeepSeek

1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com/).
2. Пополните баланс (при необходимости) в разделе биллинга.
3. Перейдите в раздел [API Keys](https://platform.deepseek.com/api_keys) и создайте новый ключ.
4. Скопируйте ключ — он показывается только один раз.

### 5. Настройте переменные окружения

```bash
cp .env.example .env
```

Откройте `.env` и заполните значения:

```dotenv
TELEGRAM_BOT_TOKEN=ваш_токен_от_botfather
DEEPSEEK_API_KEY=ваш_ключ_deepseek
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

**Важно:** файл `.env` уже добавлен в `.gitignore` — никогда не коммитьте его
и не публикуйте содержащиеся в нём ключи.

### 6. (Опционально) Настройте pre-commit хуки

Хуки проверяют код перед коммитом, включая поиск случайно закоммиченных секретов:

```bash
pip install pre-commit detect-secrets
detect-secrets scan > .secrets.baseline
pre-commit install
```

## Запуск

```bash
make run
# или напрямую:
python src/main.py
```

При успешном запуске в логах появится сообщение:

```
INFO - __main__ - Бот запущен. Модель DeepSeek: deepseek-chat
```

Откройте бота в Telegram и отправьте `/start`.

## Пример работы

```
Пользователь: /start
Бот: 👋 Привет! Я бот-прокси к DeepSeek AI.

     Просто напиши мне любое сообщение — я перешлю его в DeepSeek
     (модель deepseek-chat) и пришлю тебе ответ.

     ⚠️ Я не запоминаю историю переписки: каждое сообщение
     обрабатывается независимо от предыдущих.

     Используй /help, чтобы посмотреть список команд.

Пользователь: Объясни разницу между списком и кортежем в Python
Бот: (печатает...)
Бот: В Python список (list) изменяем — можно добавлять, удалять и менять
     элементы после создания. Кортеж (tuple) неизменяем: после создания его
     содержимое нельзя изменить. Из-за этого кортежи быстрее и могут
     использоваться как ключи словаря, а списки — нет.
```

| `/help`  | Справка по использованию и ограничениям бота |

## Ограничения и особенности

- Бот отвечает только на текстовые сообщения в **личных чатах** (групповые чаты игнорируются).
- Максимальная длина запроса пользователя ограничена переменной `MAX_INPUT_CHARS` (по умолчанию 4000 символов).
- История диалога не сохраняется — контекст предыдущих сообщений не учитывается.
- Пользователь не может сменить модель, системный промпт или иные параметры генерации.

## Безопасность

- Все секреты (токен бота, API-ключ) загружаются только из переменных окружения / `.env`.
- `.env` находится в `.gitignore` и не должен попадать в git.
- В коде нет захардкоженных ключей или админ-бэкдоров.
- Рекомендуется использовать `pre-commit` с `detect-secrets` для дополнительной защиты от случайных утечек.
