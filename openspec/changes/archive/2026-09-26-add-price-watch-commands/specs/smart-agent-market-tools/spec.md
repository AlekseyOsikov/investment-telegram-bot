# Spec Delta

## MODIFIED Requirements

### Requirement: Модели доступны только инструменты чтения

Система SHALL предоставлять модели только те инструменты сервера, которые одновременно
удовлетворяют двум условиям: сервер сам пометил их как предназначенные только для
чтения, и они входят в явный перечень разрешённых системой инструментов рыночных данных
(поиск бумаг, текущая цена, история цен). Инструмент, не удовлетворяющий любому из
условий, NOT SHALL предоставляться модели и NOT SHALL вызываться, даже если модель
назовёт его имя. Сервер для ответа smart-агента SHALL запускаться без режима
расписания, поэтому инструменты расписания ему вообще не публикуются; перечень
разрешённых инструментов — вторая линия защиты на случай ошибки конфигурации.

#### Scenario: Инструмент только для чтения

- **WHEN** сервер сообщает инструмент из перечня разрешённых с пометкой «только чтение»
- **THEN** инструмент предоставляется модели

#### Scenario: Инструмент без пометки

- **WHEN** сервер сообщает инструмент без пометки «только чтение»
- **THEN** инструмент не предоставляется модели, а попытка вызвать его по имени
  возвращается модели как ошибка, и вызова сервера не происходит

#### Scenario: Инструмент только для чтения вне перечня

- **WHEN** сервер сообщает инструмент с пометкой «только чтение», которого нет в
  перечне разрешённых
- **THEN** инструмент не предоставляется модели, а попытка вызвать его по имени
  возвращается модели как ошибка, и вызова сервера не происходит

#### Scenario: Инструменты расписания недоступны модели

- **WHEN** сервер по какой-либо причине сообщает инструменты расписания опроса цен
- **THEN** ни один из них не предоставляется модели и не вызывается по её просьбе

### Requirement: Границы данных и хранения

Серверу рыночных данных SHALL передаваться только аргументы вызовов, сформированные
моделью (например, тикер, поисковый запрос, даты). Система NOT SHALL передавать серверу
историю диалога, память агента, профиль, инварианты или иные пользовательские данные.
Промежуточные сообщения цикла вызовов и результаты инструментов NOT SHALL сохраняться
на диск: в краткосрочную память SHALL записываться только итоговая пара «вопрос —
ответ». Ответ модели при этом сохраняется как обычно и может содержать данные,
полученные от сервера.

Доступ к инструментам SHALL действовать только для основного ответа smart-агента.
Служебные вызовы модели (ведение рабочей задачи, определение старта задачи, проверка
инвариантов), а также остальные режимы бота — обычный поток вопросов, `/agent`,
`/agent_compare` и исследовательские режимы — NOT SHALL получать инструменты. Доступ
NOT SHALL зависеть от флага исследовательских команд. Это ограничение относится к
доступу модели: команды опроса цен (возможность `price-watch`) и их фоновая выдача
сводок вызывают сервер сами, без участия какой-либо модели, и не расширяют набор
инструментов, доступный модели.

#### Scenario: История не уходит серверу

- **WHEN** пользователь задаёт вопрос в чате с непустой историей и памятью
- **THEN** серверу уходят только аргументы вызовов, сформированные моделью, без
  истории, памяти, профиля и инвариантов

#### Scenario: Промежуточные сообщения не сохраняются

- **WHEN** ответ построен за несколько шагов вызова инструментов
- **THEN** в краткосрочную память записывается ровно одна пара — вопрос и итоговый
  ответ, без сообщений вызовов и результатов

#### Scenario: Служебные вызовы без инструментов

- **WHEN** после ответа выполняется служебный вызов модели, ведущий рабочую задачу
- **THEN** этот вызов выполняется без инструментов

#### Scenario: Другие режимы без инструментов

- **WHEN** пользователь работает с `/agent`, `/agent_compare` или обычным потоком
  вопросов
- **THEN** инструменты рыночных данных этим режимам не предоставляются

#### Scenario: Флаг исследовательских команд

- **WHEN** оператор выключил флаг технических/исследовательских команд
- **THEN** доступ smart-агента к инструментам рыночных данных остаётся включённым

#### Scenario: Команды опроса цен не расширяют доступ модели

- **WHEN** пользователь задаёт опрос командой `/watch` и затем задаёт вопрос smart-агенту
- **THEN** модели предоставляются те же инструменты, что и без опроса, и среди них нет ни
  одного инструмента расписания
