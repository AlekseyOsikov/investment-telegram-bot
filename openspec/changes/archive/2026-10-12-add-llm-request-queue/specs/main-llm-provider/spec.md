# Spec Delta

## ADDED Requirements

### Requirement: Обращение к провайдеру не блокирует обработку других сообщений

Система SHALL выполнять обращение к основному провайдеру так, чтобы время ожидания ответа
(включая медленную локальную модель) не останавливало обработку сообщений и команд других
пользователей, плановых задач бота и команд управления очередью. Обращения основного потока SHALL
выполняться через общую очередь обращений к основной модели.

#### Scenario: Медленная локальная модель

- **WHEN** локальная модель генерирует ответ несколько минут, и другой пользователь отправляет
  команду
- **THEN** бот отвечает на команду, не дожидаясь окончания генерации

#### Scenario: Основной поток при свободной очереди

- **WHEN** очередь свободна, и пользователь задаёт вопрос в основном потоке
- **THEN** вопрос обрабатывается сразу, пользователь видит индикатор набора и получает ответ, как
  и до введения очереди
