# Proposal

## Why

Слой `tools` `/smart_agent` сейчас даёт основному ответу данные Московской биржи
(`mcp-moex`) и спота Bybit (`mcp-bybit`), но не официальные данные Банка России —
курс валюты по ЦБ (не путать с рыночной ценой на бирже), ключевую ставку, инфляцию и
компактный макро-снимок. Это регулярно нужные, ПУБЛИЧНЫЕ справочные данные без ключей
и без единого локального проекта: пакет `atomno-mcp-cbr-rates` (PyPI, источник —
cbr.ru) устанавливается и запускается автоматически через `uvx` — оператору не нужно
клонировать и обновлять отдельный репозиторий, как для `mcp-moex`/`mcp-bybit`.
Добавление третьего источника закрывает этот пробел тем же механизмом, что уже
работает для MOEX/Bybit (проверено вручную на живом сервере: пакет действительно
запускается, отдаёт 5 инструментов чтения — `get_rate`, `history_rates`, `key_rate`,
`inflation`, `statistics`).

## What Changes

- В слой `tools` `/smart_agent` добавляется ТРЕТИЙ источник данных — Банк России
  (`atomno-mcp-cbr-rates`), независимо конфигурируемый оператором булевым флагом
  `MCP_CBR_RATES_ENABLED` (по умолчанию не заданным/`false` — возможность неактивна
  и молчит, как MOEX/Bybit при пустом каталоге). В отличие от MOEX/Bybit источник
  запускается не из локального каталога проекта (`uv run --directory <каталог>
  <программа>`), а как опубликованный пакет через `uvx atomno-mcp-cbr-rates` — у
  этого источника нет и не может быть настройки каталога, только вкл/выкл.
- Источник получает свой перечень разрешённых инструментов (`get_rate`,
  `history_rates`, `key_rate`, `inflation`, `statistics`) и, как и у MOEX/Bybit,
  имена инструментов для модели получают префикс источника (`cbr__...`) — по тому же
  механизму, что уже объединяет несколько источников в одном вопросе
  (`MultiMarketTools`). У CBR нет ни инструмента поиска, ни инструментов анализа
  истории (нет `compute_*`/`compare_*`) — цепочка ссылок на историю (`rN`),
  работающая для MOEX/Bybit, для CBR не применяется вовсе: инструментов, которые бы
  такую ссылку принимали, у источника нет.
- **Явное, документированное исключение из проверки `read_only_hint`.** Все пять
  инструментов сервера `atomno-mcp-cbr-rates` НЕ несут аннотации `read_only_hint`
  (подтверждено вручную подключением к живому серверу), хотя по описанию и сигнатуре
  каждый — чистое чтение публичных данных без параметров, похожих на побочный эффект.
  Действующее правило («нет аннотации — не read-only», вторая линия защиты после
  явного перечня) для MOEX/Bybit НЕ ослабляется: вводится узкий, явно
  промаркированный в коде и документации способ пометить КОНКРЕТНЫЙ источник как
  «проверенный вручную, аннотация необязательна» — применяется только к источнику
  CBR по этому изменению, а не превращается в общее правило «допускаем инструменты
  без аннотации». Перечень разрешённых имён (вторая линия защиты) для CBR обязателен
  так же, как и для MOEX/Bybit — исключение снимает только первое условие, не оба.
- Сообщение слоя получает АБЗАЦ CBR (аналог абзаца цепочки анализа MOEX/Bybit, но не
  привязанный к наличию инструментов анализа — у источника их нет): официальный курс
  ЦБ — это НЕ рыночная цена (устанавливается Банком России один раз в день,
  действует со следующего рабочего дня публикации), `history_rates` ограничен 366
  днями за один вызов (для более длинных периодов — повторные вызовы), и
  `statistics` не заменяет отдельные вызовы, если нужны детали (полная история,
  конкретный диапазон лет для инфляции).
- `/smart_agent_show` показывает статус CBR отдельной строкой наравне с MOEX/Bybit.
- **Не меняется и явно не предлагается**: у CBR нет режима записи/опроса по
  расписанию (`/watch*` остаётся только для MOEX); версия пакета не пинуется отдельной
  переменной — `uvx` использует свой обычный кэш/резолюцию последней версии; личные
  данные пользователя (суммы обмена, счета) не собираются и не передаются серверу —
  запросы содержат только код валюты и даты.

## Capabilities

### New Capabilities

(нет — источник добавляется в существующий слой `tools`, а не вводит новый механизм)

### Modified Capabilities

- `smart-agent-market-tools`: добавляется третий источник (Банк России) со своим
  способом конфигурации (булев флаг + `uvx`, без каталога), своим перечнем
  разрешённых инструментов, документированным исключением из требования
  `read_only_hint` и собственным абзацем сообщения слоя (не привязанным к
  инструментам анализа, которых у источника нет).

## Impact

- `src/config.py` — новая переменная `MCP_CBR_RATES_ENABLED` (булев флаг по образцу
  `RESEARCH`/`PRICE_WATCH`, а не `MCP_MOEX_DIR`-подобный путь — у источника нет
  каталога).
- `src/mcp_integration/market_session.py` — новый способ собрать команду запуска
  (`uvx <пакет>`, без `--directory`), новый перечень разрешённых инструментов CBR,
  явный (не выведенный, а прописанный по имени источника) флаг «аннотация
  необязательна» именно для источника CBR.
- `src/agents/market_tools.py` — абзац сообщения слоя для CBR (не через механизм
  `analytics_available`, у него другое условие показа), подпись/описание источника
  для `/smart_agent_show` и текстов доступности/выключения.
- `src/agents/smart_agent.py` — источник CBR добавляется в перечень настраиваемых
  источников (без каталога — только имя и флаг включения).
- `tests/test_market_tools.py` — тесты на: команду запуска `uvx`, допуск инструментов
  без аннотации именно для промаркированного источника (и отказ для непромаркированного
  гипотетического), отсутствие ref-цепочки у CBR, содержимое абзаца CBR.
- `.env.example`, `README.md`, `CLAUDE.md` — документация новой переменной,
  исключения из `read_only_hint` и структуры сообщения слоя.
- Не затрагивается: `src/price_watch/`, `src/mcp_integration/watch_session.py`,
  `src/mcp_integration/tools_command.py`/`client.py` (`/mcp_tools`), реестр ссылок на
  историю MOEX/Bybit (`r1`, `r2`, …), `MAIN_CLIENT`/`MAIN_MODEL`/`SYSTEM_PROMPT`.

## Открытые вопросы, закрытые явно с владельцем проекта до написания артефактов

- **Отсутствие `read_only_hint` у всех инструментов сервера**: решено ДОВЕРИТЬ этому
  источнику как документированному, вручную проверенному исключению (а не ждать
  обновления сервера и не отдавать инструменты только через `/mcp_tools`-диагностику).
- **Форма конфигурации без локального каталога**: решено использовать простой булев
  флаг включения (`MCP_CBR_RATES_ENABLED`), без отдельной переменной на версию пакета.
