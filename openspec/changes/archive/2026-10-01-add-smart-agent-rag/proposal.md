# Proposal

## Why

Офлайн-пайплайн `rag/` уже строит и хранит индекс учебного корпуса документов,
а `/research_chunking_compare` позволил сравнить стратегии чанкинга, но индекс пока нигде не
участвует в ответах: `/smart_agent` отвечает только из знаний модели и, при настроенных
источниках, из рыночных данных. Вопросы по теме корпуса должны
опираться на материалы корпуса, а не на память модели. Тема — логичный следующий шаг после
индексации: теперь известно, какая стратегия чанкинга подходит, и можно использовать индекс в
ответах.

## What Changes

- Перед основным ответом `/smart_agent` система строит эмбеддинг вопроса, ищет релевантные чанки
  в индексе одной стратегии (по умолчанию `structural`, настройка оператора в `.env`), отбрасывает
  чанки ниже порога релевантности и объединяет оставшиеся с вопросом в последнем `user`-сообщении
  запроса к LLM. Поиск выполняется один раз на вопрос, до ветвления на путь с инструментами
  рыночных данных и без них, поэтому RAG работает в обоих случаях.
- В краткосрочную память пишется исходный вопрос пользователя без чанков: пара «вопрос — ответ»
  сохраняется как обычно.
- Новый слой `rag` в `enabled_layers`, переключаемый командой `/smart_agent_toggle rag`; по
  умолчанию включён, старые файлы памяти без ключа читаются как «включён». Без индекса слой
  ничего не делает и молчит.
- Блок справочных материалов подаётся модели как ДАННЫЕ, а не инструкции, не отменяет и не
  ослабляет обязательные предупреждения `SYSTEM_PROMPT`; инварианты остаются приоритетнее.
- Ожидание сервера эмбеддингов ограничено бюджетом оператора (по умолчанию 5 секунд, настройка
  в `.env`); `embed_texts` получает необязательный параметр бюджета, индексация и
  research-команды остаются на прежнем расписании повторов.
- Сбой поиска (нет индекса, Ollama недоступна, тайм-аут) не роняет ответ: вопрос уходит в LLM без
  справочных материалов, пользователь получает предупреждение.
- После ответа пользователь видит источники (документ, фрагмент, оценка); `/smart_agent_show`
  показывает статус слоя и последний собранный контекст с блоком материалов.
- Служебные вызовы LLM (автомат задачи, детектор старта, ревизор инвариантов) справочные
  материалы не получают.
- Отдельной задачей — калибровка порога релевантности на реальных запросах (релевантные,
  пограничные и нерелевантные корпусу), значение по умолчанию записывается по её итогам.

Ломающих изменений нет: чаты без индекса и с выключенным слоем ведут себя как раньше.

## Capabilities

### New Capabilities

- `smart-agent-rag`: использование индекса документов в основном ответе `/smart_agent` — поиск
  чанков по вопросу, объединение с вопросом, порог релевантности, выбор стратегии оператором,
  переключение слоем `rag`, отказоустойчивость, видимость источников, границы данных и хранения.

### Modified Capabilities

Нет: существующие требования `rag-indexing` (построение индекса и research-команды) и
`smart-agent-market-tools` (инструменты рыночных данных, передача данных серверам MCP) не
меняются — новый слой обращается к индексу и к серверу эмбеддингов, а не к MCP-серверам.

## Impact

- Код: `src/agents/smart_agent.py` (слой `rag`, поиск в `ask()`, сборка последнего
  `user`-сообщения, статус слоя), новый чистый модуль правил и текстов слоя в `src/agents/`,
  `src/agents/smart_agent_command.py` (алиас `rag` в `/smart_agent_toggle`, строки источников,
  блок в `/smart_agent_show`), `src/config.py` (стратегия, `RAG_TOP_K`, `RAG_MIN_SCORE`,
  `RAG_SEARCH_TIMEOUT_SECONDS`, проверка значений), `src/providers/embeddings_client.py`
  (необязательный бюджет времени), `.env.example`.
- Зависимости: использует существующие `rag/index_store.search()` и
  `providers/embeddings_client.embed_texts()`; новых пакетов нет.
- Поведение: каждый вопрос к `/smart_agent` при наличии индекса вызывает Ollama для эмбеддинга и
  при срабатывании порога добавляет токены в запрос; для уже существующих чатов это включается
  без их действий (слой включён по умолчанию).
- Данные: текст вопроса целиком уходит в embeddings-бэкенд (`EMBEDDINGS_BASE_URL`, сейчас
  локальный Ollama) — новый канал, которого нет у слоя `tools`.
- Документация: `CLAUDE.md` (`src/agents/`, корневой), README.
