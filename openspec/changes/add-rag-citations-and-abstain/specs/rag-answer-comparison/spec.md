# Spec Delta

## MODIFIED Requirements

### Requirement: Контрольный набор вопросов с ожиданиями и источниками

Система SHALL использовать контрольный набор вопросов по документам корпуса, заданный
оператором файлом, путь к которому задаётся настройкой оператора. Файл набора NOT SHALL входить в
репозиторий кода бота: вопросы и ожидаемые факты привязаны к корпусу оператора, который в
репозиторий тоже не входит. Для каждого вопроса набор SHALL содержать формулировку,
тип вопроса (по специфике корпуса, по общему понятию, о событии после даты знаний модели),
перечень ожидаемых ключевых фактов, которые должны присутствовать в хорошем ответе, и перечень
документов, на которые ответ должен опираться. Вопрос набора MAY дополнительно содержать историю
диалога — перечень предыдущих вопросов пользователя от старых к новым, после которых задан этот
вопрос (многоходовый вопрос); отсутствие истории означает самостоятельный вопрос. Вопрос набора
MAY быть помечен как вопрос вне корпуса с ожиданием отказа («не знаю»); для такого вопроса
перечни фактов и документов NOT SHALL требоваться. Перед запуском система SHALL проверять набор: у
каждого вопроса без пометки об ожидаемом отказе есть непустые формулировка, факты и источники, у
вопроса с такой пометкой — непустая формулировка, у заданной истории — только непустые строки, а
сам набор не пуст. При недопустимом наборе система NOT SHALL начинать прогон и SHALL сообщить
пользователю, что набор некорректен. Если файл набора не найден, система NOT SHALL начинать прогон
и SHALL сообщить, где файл нужно создать и в каком формате его заполнить.

#### Scenario: Набор допустим

- **WHEN** пользователь запускает сравнение, а набор содержит вопросы с фактами и источниками
- **THEN** прогон начинается

#### Scenario: Набор с многоходовыми вопросами допустим

- **WHEN** у некоторых вопросов набора задана история из непустых строк
- **THEN** набор принимается, а вопросы без истории обрабатываются как прежде

#### Scenario: Вопрос вне корпуса допустим без фактов

- **WHEN** вопрос набора помечен ожиданием отказа и не содержит фактов и источников
- **THEN** набор принимается

#### Scenario: Файл набора не найден

- **WHEN** пользователь запускает сравнение, а файла набора по заданному пути нет
- **THEN** прогон не начинается, а пользователь получает сообщение с путём, где создать файл, и
  кратким описанием формата

#### Scenario: Набор недопустим

- **WHEN** в наборе есть вопрос без пометки об ожидаемом отказе, у которого нет ожидаемых фактов
  или источников
- **THEN** прогон не начинается, а пользователь получает сообщение о некорректном наборе

#### Scenario: Недопустимая история

- **WHEN** у вопроса история не является списком или содержит пустую строку
- **THEN** прогон не начинается, а пользователь получает сообщение о некорректном наборе с
  номером вопроса

## ADDED Requirements

### Requirement: Проверка источников, цитат и режима «не знаю» в сравнении ответов

Для каждого вопроса набора система SHALL проверять ответ режима с включённым слоем материалов и
сообщать в итоговом отчёте: есть ли в ответе источники, есть ли в нём проверенные цитаты, какова
доля проверенных цитат среди написанных моделью (проверка по тексту фрагментов, см.
`smart-agent-rag`), и совпадает ли смысл ответа со смыслом проверенных цитат. Совпадение смысла
SHALL оценивать отдельное обращение к модели по тексту вопроса, ответа и проверенных цитат с
вердиктом «подтверждается», «подтверждается частично» или «не подтверждается» и перечнем
утверждений ответа, которых нет в цитатах; оценка NOT SHALL получать сведения о режиме. Для
вопроса вне корпуса ожидание выполнено, если бот ответил режимом «не знаю»; для вопроса по
корпусу ответ «не знаю» SHALL считаться пропуском, а не успехом. Сводка SHALL показывать долю
ответов с источниками, долю ответов с проверенными цитатами, среднюю долю проверенных цитат,
распределение вердиктов совпадения смысла и число верных и неверных отказов. Вопросы без оценки
SHALL исключаться из соответствующих долей с указанием числа таких вопросов.

#### Scenario: Источники и цитаты есть в каждом ответе

- **WHEN** на каждый вопрос по корпусу ответ содержит источники и проверенные цитаты
- **THEN** сводка показывает 100% ответов с источниками и 100% ответов с цитатами

#### Scenario: Ответ расходится с цитатами

- **WHEN** ответ содержит утверждение, которого нет в проверенных цитатах
- **THEN** вердикт по вопросу «подтверждается частично» или «не подтверждается» и перечислены
  утверждения без опоры

#### Scenario: Вопрос вне корпуса

- **WHEN** вопрос помечен ожиданием отказа и бот ответил режимом «не знаю»
- **THEN** вопрос учитывается как верный отказ, а ответ модели не оценивается по фактам

#### Scenario: Ложный отказ

- **WHEN** на вопрос по корпусу бот ответил режимом «не знаю»
- **THEN** вопрос учитывается как пропуск и отмечается в таблице по вопросам

#### Scenario: Оценка не знает режима

- **WHEN** система просит оценить совпадение смысла ответа и цитат
- **THEN** в запросе на оценку нет указания на состояние слоя материалов
