# Proposal

## Why

Слой `rag` у `/smart_agent` подаёт модели фрагменты корпуса, но не требует от неё ссылаться на
них: источники под ответом строит код по списку поданных чанков (а не по тому, что модель
реально использовала), цитат нет, и проверить, опирается ли ответ на материалы, нельзя. Хуже
того, когда ни один чанк не достиг порога, спека требует отвечать «как без слоя» — то есть из
знаний модели, без предупреждения, что в материалах ничего не нашлось. Для бота, отвечающего о
деньгах, это главный источник правдоподобных, но не подтверждённых утверждений.

## What Changes

- **Цитаты в ответе по материалам.** Правила слоя обязывают модель закончить ответ блоком
  «Цитаты:» с маркерами `[n] «…»` (n — номер фрагмента в поданном блоке). Код разбирает блок,
  проверяет каждую цитату как подстроку текста фрагмента n (после нормализации пробелов и
  регистра), отбрасывает непроверенные и сам строит строки источников и цитат. Выдуманная
  модель цитата или номер до пользователя не доходят.
- **Источники — по фактически процитированным фрагментам**: документ, номер фрагмента
  (`chunk_index`) и сквозной `chunk_id`, оценка близости. Если модель не процитировала ничего
  проверяемого, показываются поданные фрагменты с явной пометкой «цитаты не подтверждены».
  Если ответ построен по материалам, но проверенных цитат нет, делается один повторный вызов с
  требованием добавить цитаты; после него — честная пометка.
- **Режим «не знаю».** При включённом слое `rag` с построенным индексом и успешным поиском, но
  без чанков выше порога, если слой `tools` не может участвовать в ответе, бот НЕ вызывает
  модель: отвечает фиксированным текстом «в справочных материалах нет достаточно близкого
  ответа, уточните вопрос» с подсказкой, как переформулировать. Если слой `tools` может
  участвовать, модель вызывается как раньше, но получает системное указание не выдавать
  ответ за подтверждённый материалами, а пользователь видит пометку «в материалах ничего
  подходящего не нашлось». **BREAKING** для сценария «вопрос не по теме корпуса»: раньше бот
  отвечал из знаний модели без пометки.
- **«Раздел» = `chunk_index` + `chunk_id`**, без переиндексации. Заголовок раздела в индексе —
  отдельное будущее изменение `rag-indexing`.
- **Проверка на контрольных вопросах** в `/research_rag_compare`: метрики «есть источники»,
  «есть цитаты», доля проверенных цитат, оценка судьёй «смысл ответа соответствует цитатам»,
  вопросы вне корпуса с ожиданием «не знаю». Файл вопросов по-прежнему лежит в `data/` и не
  коммитится; в коде, тестах и документации — только вымышленные названия.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `smart-agent-rag`: меняются «Порог релевантности» (пустая выдача больше не означает «как без
  слоя») и «Источники видны пользователю» (источники по процитированным фрагментам, `chunk_id`,
  цитаты); добавляются требования «Цитаты в ответе по материалам, проверенные по тексту
  фрагментов» и «Режим „не знаю“ при отсутствии релевантных материалов».
- `rag-answer-comparison`: меняется «Контрольный набор вопросов с ожиданиями и источниками»
  (вопрос с ожиданием отказа не требует фактов и источников); добавляется требование «Проверка
  источников, цитат и режима „не знаю“ в сравнении ответов».

## Impact

- Код: `agents/rag_context.py` (правила: обязанность цитировать; разбор и проверка блока цитат,
  форматирование источников и цитат, текст отказа и пометки — чистые функции),
  `agents/smart_agent.py` (`ask()`: ранний отказ, повтор за цитатами, поля
  `SmartAgentAnswer`), `agents/smart_agent_command.py` (вывод цитат и пометок),
  `research/rag_compare_eval.py` и `research/rag_compare.py` (метрики, судья цитат, вопросы
  `expect_abstain`), тесты `tests/test_rag_context.py`, `tests/test_rag_compare_eval.py`.
- Поведение: каждый ответ по материалам может стоить на один вызов модели больше (повтор);
  вопросы не по теме корпуса без `tools` отвечаются без вызова модели.
- Документация: `CLAUDE.md` (доменные правила слоя `rag`), `src/agents/CLAUDE.md`,
  `src/research/CLAUDE.md`, `README.md` (поведение «не знаю», цитаты).
- Конфигурация, индекс и зависимости не меняются; переиндексация не нужна.
