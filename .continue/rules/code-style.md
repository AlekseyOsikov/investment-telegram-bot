Проект: Telegram-бот для инвестиционных рекомендаций. Python ≥ 3.10, python-telegram-bot 20.x (async),
openai SDK, ruff (line-length 100, правила E,F,I,UP,B), pytest. Отвечай по-русски. Комментарии,
докстринги и тексты пользователю — на русском, идентификаторы — на английском.

## Структура
`src/<подсистема>/` = `__init__.py` + `rules.py` + `texts.py` + `commands.py` (+ `CLAUDE.md`).
- `rules.py` — ЧИСТЫЕ правила: данные → решение. Без Telegram, сети, диска и `config`.
- `texts.py` — ЧИСТЫЕ тексты пользователю (русский, без parse_mode), оговорки — константами.
- `commands.py` — тонкий хендлер: читает ввод, зовёт чистые функции, отвечает.
- Тесты: `tests/test_<подсистема>_<модуль>.py`, функции `test_*` без классов, без сети и моков.
- Новая подсистема регистрируется в 5 местах: `main.py` (импорт по алфавиту + `add_handler`),
  `help_command`, `README.md` (таблица команд И дерево), карта `src/` в корневом `CLAUDE.md`,
  `src/<подсистема>/CLAUDE.md`.

## Naming
Модули `snake_case`; обработчик `<команда>_command`; фабрика `build_<имя>_handler(s)`; константы
`UPPER_SNAKE`; приватное с `_`; команда `/подсистема_действие`.

## Шаблон файла в `src/`
Докстринг модуля (что решает и чего не знает, ссылка на тесты) → `from __future__ import annotations`
→ импорты (stdlib, сторонние, проектные) → константы → функции. В тестах `__future__` не нужен.

```python
"""Чистые правила <подсистемы>: что решает модуль. Тесты — `tests/test_<подсистема>_rules.py`."""

from __future__ import annotations

KINDS: dict[str, str] = {"a": "Первое"}


def normalize(raw: str) -> str:
    """Что принимает и что возвращает."""
    return " ".join(raw.casefold().split())
```

Хендлер: `CommandHandler("имя", имя_command, filters=filters.ChatType.PRIVATE)` — фильтр личного чата
у КАЖДОГО нового обработчика.

## Запрещено
- Логика поиска/разбора внутри `async def …_command` (выноси в `rules.py` + тест).
- Один общий `except Exception` вокруг вызова модели: ловить ошибки OpenAI SDK раздельно, сообщение
  по-русски с `MAIN_CLIENT_LABEL`, а не захардкоженное «DeepSeek».
- `os.getenv` и `load_dotenv()` вне `config.py`.
- Обработчик без `filters.ChatType.PRIVATE`; ответ об инвестициях без оговорки.
- Слова «гарантированно», «точно вырастет», «рекомендуем купить» в любом тексте пользователю.
- Тест запретных формулировок только по части текстов: перебирай ВСЕ ответы целиком и проверяй
  оговорку в каждом.
- Поиск «похожего» по подстроке без минимальной длины запроса.
- Секреты, `.env`, номера счетов и карт, суммы на счетах, ИНН — не читать, не запрашивать, не хранить.
- Команды и параметры, позволяющие пользователю чата менять модель, провайдера или SYSTEM_PROMPT.

## Домен
Бот НЕ лицензированный финансовый советник; оговорка «не является индивидуальной инвестиционной
рекомендацией» — константой в `texts.py` и в каждом ответе об инвестициях. Формулировки отражают
неопределённость рынка. «Изменение цены», а не «доходность».
