# Справка по боту: общие сведения

Этот раздел отвечает на вопросы о том, как пользоваться ботом и что делать, если что-то не
работает. Он описывает работу самого бота, а не рынки и не инвестиции.

## Важная оговорка

Бот не является лицензированным финансовым советником. Его ответы и сводки — справочная
информация, а не индивидуальная инвестиционная рекомендация, и они не гарантируют доходность.
Перед принятием финансовых решений проконсультируйтесь с лицензированным специалистом.

## Что нельзя присылать боту

Не присылайте номера счетов и карт, паспортные данные, ИНН, суммы на счетах и другие
чувствительные сведения. Бот их не запрашивает и не проверяет ввод на их наличие: если вы
отправили такие данные сами, они могут попасть в память режима или к провайдеру модели.

## Какие бывают режимы

Обычное сообщение боту — это отдельный вопрос без памяти о предыдущих. Для диалога с памятью
есть режимы `/agent` и `/smart_agent`, для опроса цен по расписанию — команды `/watch`, для
вопросов о самом боте — режим `/support`. Выйти из любого режима диалога можно командой
`/cancel`.
