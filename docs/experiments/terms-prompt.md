# Промпт эксперимента «Rules» (День 1): команда /terms

Один и тот же дословный промпт для обеих генераций (v1 — до правки правил, v2 — после).
Не редактировать между прогонами.

```
Добавь в бота команду /terms — глоссарий инвестиционных терминов.

/terms без аргументов — список доступных терминов.
/terms <термин> — определение термина; регистр и пробелы по краям не важны;
если термина нет — предложить похожие.

Нужно 8 терминов (например: дивиденд, купон, ликвидность, волатильность,
диверсификация, облигация, акция, индекс). Словарь хранится в коде, сеть и LLM
не используются. Команда работает в личном чате.

Реализуй по принятым в проекте соглашениям, включая регистрацию команды,
справку, тесты и документацию. Один проход, без уточняющих вопросов.
```

## Условия замера

- Обе генерации стартуют от одного коммита кода; v2 — от коммита с правилами v2.
- Проверки только через `.venv/bin/...` (Python 3.11): `python -m compileall -q src`,
  `ruff check` по новым и изменённым файлам, `pytest tests/`.
- Критерии стиля оцениваются чек-листом 0/1: структура `rules/texts/commands`,
  `build_terms_handlers()`, регистрация в `main.py`, строка в `/help`, README и вложенный
  `CLAUDE.md`, оговорка «не советник», фильтр личного чата, русские строки, докстринг модуля,
  `from __future__ import annotations`, тесты чистых функций.
