# Сценарий: Приветствие и справка
Чат: личный

Пользователь впервые открывает бота: приветствие и справка должны явно говорить, что бот не
лицензированный финансовый советник.

## Шаг: /start
Отправить: /start
Ожидать: не являюсь лицензированным финансовым советником
Ожидать: не индивидуальная инвестиционная рекомендация
Ожидать: /help

## Шаг: /help
Отправить: /help
Ожидать: /start
Ожидать: /queue
Ожидать: не является лицензированным финансовым советником
