# Сценарий: Профиль и инвариант smart-агента
Чат: личный

Создать → проверить, что появилось → удалить. Профиль и инвариант пишутся только явными
командами, без вызова модели. Данные — вымышленные.

## Шаг: без профиля инвариант не добавить
Отправить: /smart_agent_invariant_add без плеча
Ожидать: нет активного профиля
Ожидать: /smart_agent_profile

## Шаг: открыть выбор профиля
Отправить: /smart_agent_profile
Ожидать: нет активного профиля
Ожидать: Новый профиль

## Шаг: новый профиль
Нажать: Новый профиль
Ожидать: название нового профиля

## Шаг: имя профиля
Отправить: Тестовый
Ожидать: (1/7)

## Шаг: стиль
Отправить: коротко и по делу
Ожидать: (2/7)

## Шаг: опыт
Отправить: пропустить
Ожидать: (3/7)

## Шаг: формат
Отправить: пропустить
Ожидать: (4/7)

## Шаг: риск
Отправить: пропустить
Ожидать: (5/7)

## Шаг: горизонт
Отправить: пропустить
Ожидать: (6/7)

## Шаг: интересы
Отправить: пропустить
Ожидать: (7/7)

## Шаг: последний пункт, профиль создан
Отправить: пропустить
Ожидать: «Тестовый» создан и активирован

## Шаг: добавить инвариант
Отправить: /smart_agent_invariant_add инструменты: без криптовалют
Ожидать: Инвариант №1
Ожидать: без криптовалют

## Шаг: инвариант виден в списке
Отправить: /smart_agent_invariant_show
Ожидать: 1. [инструменты] без криптовалют

## Шаг: снять инвариант
Отправить: /smart_agent_invariant_remove 1
Ожидать: Инвариант №1 снят

## Шаг: список снова пуст
Отправить: /smart_agent_invariant_show
Ожидать: Инвариантов пока нет

## Шаг: удалить профиль
Отправить: /smart_agent_profile_delete Тестовый
Ожидать: «Тестовый» удалён
