# Сценарий: Очередь вопросов пуста
Чат: личный

## Шаг: список очереди
Отправить: /queue

## Шаг: отмена пустой очереди
Отправить: /queue_cancel
Ожидать: Отменять нечего

## Шаг: отмена по номеру тоже безопасна
Отправить: /queue_cancel 3
Ожидать: Отменять нечего
