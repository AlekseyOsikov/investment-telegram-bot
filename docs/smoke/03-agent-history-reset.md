# Сценарий: История агента и её сброс
Чат: личный

Без вопросов к модели: история пуста, сброс проходит и повторно безопасен.

## Шаг: история пуста
Отправить: /agent_history
Ожидать: История диалога с агентом пуста

## Шаг: сброс
Отправить: /agent_reset
Ожидать: История диалога с агентом очищена

## Шаг: история по-прежнему пуста
Отправить: /agent_history
Ожидать: История диалога с агентом пуста
