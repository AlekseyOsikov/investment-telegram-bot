# Новая команда бота

Источник правил — `docs/code-style.md` (разделы 4–10) и доменные запреты корневого `CLAUDE.md`.
Скилл — порядок действий, а не замена этих файлов; при расхождении прав файл правил.

## Порядок

1. **Прочитай образец** ближайшей подсистемы: `src/news_digest/` (команды + тексты + правила) или
   `src/llm_queue/commands.py` (простые команды). Открой `rules.py`, `texts.py`, `commands.py`
   и `tests/test_news_digest_texts.py` — копируй структуру, не изобретай свою.
2. **Реши, нужен ли OpenSpec.** Заметное изменение поведения бота — через `/opsx:*`; мелкая
   справочная команда без хранения данных — обычным порядком. Если неясно — скажи в итоге.
3. **Создай пакет** `src/<подсистема>/`: `__init__.py`, `rules.py` (чистые правила), `texts.py`
   (все тексты пользователю + оговорки константами), `commands.py` (тонкий хендлер +
   `build_<имя>_handler(s)` с `filters.ChatType.PRIVATE`). Каждый модуль: докстринг →
   `from __future__ import annotations` → импорты → константы.
4. **Оговорки.** Если команда касается инвестиций — «бот не лицензированный финансовый советник»
   и «не рекомендация и не прогноз» в КАЖДОМ ответе (как `news_digest/texts.py`). Без гарантий,
   оценок и советов.
5. **Зарегистрируй**: `main.py` (импорт в алфавитном порядке + `add_handler`), `help_command`,
   `README.md` (таблица команд И дерево каталогов), карта `src/` в `CLAUDE.md`, новый
   `src/<подсистема>/CLAUDE.md` по образцу `src/llm_queue/CLAUDE.md`.
6. **Тесты** `tests/test_<подсистема>_rules.py` и `…_texts.py`: чистые функции без сети и
   Telegram; тест наличия оговорки и тест запретных формулировок (регулярка по образцу
   `GUARANTEE` из `tests/test_news_digest_texts.py`).
7. **Проверь** (раздел 10 `docs/code-style.md`):
   - `.venv/bin/python -m compileall -q src`
   - `.venv/bin/ruff check` по новым и изменённым файлам — новых замечаний быть не должно,
     включая `I001` в `main.py`
   - `TELEGRAM_BOT_TOKEN=x DEEPSEEK_API_KEY=x .venv/bin/pytest tests/ -q`
8. **Итог**: перечисли созданные и изменённые файлы, результаты трёх проверок и то, что не
   проверено (живой Telegram).

## Не делай

- Не добавляй команды, меняющие модель, провайдера или системный промпт, и сбор сумм/личных
  финансовых данных — это отдельные решения владельца.
- Не коммить без просьбы. Не копируй в код и документацию названия документов корпуса.
